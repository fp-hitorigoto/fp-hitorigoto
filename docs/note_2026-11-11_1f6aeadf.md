# 国民健康保険料の上限が96万円に。自分の保険料は、どう決まるの？

国民健康保険（国保）の保険料について、気になるニュースが報じられました。厚生労働省は、所得の高い人が納める保険料のうち「医療分」の年間上限額を、2027年度から3万円引き上げて96万円とする方針を示し、11月11日の部会で了承された、と伝えられています。

「上限が上がる」と聞くと、身構えてしまいますよね。でも、まずは落ち着いて、中身を整理してみましょう。

■ 今回の見直しで、何が変わるの？

・医療分の年間上限額が、93万円から96万円に（3万円の引上げ）
・時期は、2027年度から
・上限に達する世帯は、年収約1,140万円以上から、約1,170万円以上に
・厚生労働省の推計では、上限に達するのは加入者全体の1.73%

3万円を月あたりにならすと、2,500円です。ただ、この上限に達しているのは、もともと所得の高い世帯に限られます。大半の方は上限に届かないので、今回の見直しで保険料が直接上がるわけではありません。

狙いは、高所得層の負担を増やすことで、中間所得層の保険料の伸びを抑えることとされています。国保料の上限の引上げは、2022年度から6年連続です。

なお、これは報道に基づく内容です。実際の上限額は、今後の政令の改正で決まります。

■ そもそも国保料は、どう決まるの？

「自分の保険料の中身を、よく知らない」という方は、意外と多いものです。国保料は、大きく3つの区分で構成されています。

・医療分（医療にかかる費用に充てる部分）
・後期高齢者支援金分（75歳以上の方の医療を支えるための部分）
・介護分（40歳から64歳の方が対象）

それぞれに年間の上限（賦課限度額）があり、今回話題になっているのは、そのうち医療分の上限です。

計算の中心になるのは、次の2つです。

・所得割：前年の所得に応じてかかる部分
・均等割：加入者の人数に応じてかかる部分

自治体によっては、世帯単位でかかる「平等割」を設けているところもあります。料率や計算方法は市区町村ごとに違うため、同じ所得でも、住む場所によって保険料が変わるのが国保の特徴ですね。

■ 会社員の健康保険との違い

会社員の健康保険は、給与をもとにした保険料を、会社と本人で折半する仕組みです。協会けんぽの全国平均の保険料率は、2026年度は9.9%です。また、扶養に入っている家族は、人数が増えても保険料は増えません。

一方、国保には、会社員の健康保険のような扶養の考え方がなく、加入者一人ひとりが被保険者になります。そのため、家族の人数に応じてかかる均等割が、世帯の負担に反映されます。事業主負担もないので、保険料は全額を自分で負担することになります。

会社を辞めて独立したり、早期退職をしたりして国保に入ると、保険料の感覚が変わりやすいと言われます。フリーランスや個人事業主、退職後の方は、この違いを知っておくと安心です。

■ 立場によって、影響の方向が変わります

・上限に達している高所得の国保加入者：負担が増える可能性があります
・中間所得層の国保加入者：負担の伸びを抑えることが目的とされています。ただ、実際の効果は、今後の制度設計や自治体ごとの料率の決め方にもよるとみられます
・会社員など被用者保険の加入者：今回は国保の仕組みの見直しなので、直接の対象ではありません

どの立場の方にとっても、「自分の保険料がどの区分で、どう計算されているのか」を知っておくことは大切です。

■ 今日からできる、自分ごとのチェック

もしあなたが国保に加入しているなら、次の点を確認してみてください。

① 納付通知書を見る：医療分・後期高齢者支援金分・介護分の内訳が書かれています
② 所得割と均等割の金額を確認する：保険料が、所得と人数のどちらに左右されやすいかが見えてきます
③ お住まいの自治体の料率を調べる：同じ所得でも、自治体によって金額が違うことがあります
④ 前年の所得を意識する：所得割は前年の所得をもとに計算されるので、収入が大きく変わった翌年は、保険料の変化にも備えておきたいところです

また、今は会社員でも、将来、独立や退職で国保に入る可能性は、誰にでもあります。早めに仕組みを知っておくと、慌てずに済みます。

■ まとめ

・医療分の年間上限を、2027年度から93万円→96万円に引き上げる方針が、11月11日の部会で了承されたと報じられています
・上限に達するのは、年収約1,170万円以上の世帯（全体の約1.7%）
・大半の加入者には、直接の影響はありません
・実際の上限額は、今後の政令の改正で決まります

保険料のニュースは、つい「自分には関係ない」と流してしまいがちです。でも、国保料は家計の中でも大きな固定費の一つですよね。今回の報道をきっかけに、一度ご自身の納付通知書を開いてみてはいかがでしょうか。
