# 国民健康保険料の上限額が引き上げへ｜自分の保険料はどう決まる?

国民健康保険(国保)の保険料について、気になるニュースが報じられました。NHKの報道によると、厚生労働省は、所得の高い人が納める保険料のうち「医療分」の年間上限額を、来年度から3万円引き上げて96万円とする方向で調整しているそうです。狙いは、中間所得層の保険料負担の伸びを抑えることとされています。

「上限が上がる」と聞くと身構えてしまいますが、まずは落ち着いて中身を整理してみましょう。

## 「方向で調整」の段階です

まず押さえておきたいのは、これが決定事項ではなく、あくまで「方向で調整」という段階だということです。後期高齢者支援金分や介護分の扱いなど、細かい制度設計は今後の公表を待つ必要があります。

3万円を月あたりにならすと2,500円です。ただ、この上限に達しているのは、もともと所得の高い世帯に限られます。多くの方は上限に届かないので、今回の見直しで保険料が直接上がるわけではない、と考えられます。

## そもそも国保料はどう決まる?

「自分の保険料の中身を、よく知らない」という方は意外と多いものです。国保料は、大きく3つの区分で構成されています。

- 医療分(医療にかかる費用に充てる部分)
- 後期高齢者支援金分(75歳以上の方の医療を支えるための部分)
- 介護分(40歳から64歳の方が対象)

それぞれに年間の上限(賦課限度額)があり、今回話題になっているのは、そのうち医療分の上限です。

計算の中心になるのは、次の2つです。

- **所得割**:前年の所得に応じてかかる部分
- **均等割**:加入者の人数に応じてかかる部分

自治体によっては、世帯単位でかかる「平等割」を設けているところもあります。料率や計算方法は市区町村ごとに違うため、同じ所得でも住む場所によって保険料が変わるのが国保の特徴ですね。

## 会社員の健康保険との違い

会社員の健康保険は、給与をもとにした保険料を会社と本人で分け合う仕組みです。また、扶養に入っている家族は、人数が増えても保険料は増えません。

一方、国保には会社員の健康保険のような扶養の考え方がなく、加入者一人ひとりが被保険者になります。そのため、家族の人数に応じてかかる均等割が、世帯の負担に反映されます。事業主負担もないので、保険料は基本的に自分で負担することになります。

「会社を辞めて独立したら、保険料の感覚が変わった」という声は、実際によく耳にします。フリーランスや個人事業主、早期退職をされた方などは、この違いを知っておくと安心です。

## 立場によって影響の方向が変わります

今回の見直しは、立場によって受け止め方が変わります。

- **上限に達している高所得の国保加入者**:負担が増える可能性があります。
- **中間所得層の国保加入者**:報道では、負担の伸びを抑えることが目的とされています。ただ、実際にどの程度の効果があるかは、今後の制度設計や自治体ごとの料率の決め方にもよるとみられます。
- **会社員など被用者保険の加入者**:今回の話題は国保の仕組みの見直しなので、直接の対象ではありません。

どの立場の方にとっても、「自分の保険料がどの区分で、どう計算されているのか」を知っておくことは大切です。

## 今日からできる、自分ごとのチェック

もしあなたが国保に加入しているなら、ぜひ次の点を確認してみてください。

1. **納付通知書を見る**:医療分・後期高齢者支援金分・介護分の内訳が書かれています。
2. **所得割と均等割の金額を確認する**:自分の保険料が、所得と人数のどちらに左右されやすいかが見えてきます。
3. **お住まいの自治体の料率を調べる**:同じ所得でも、自治体によって金額が違うことがあります。
4. **前年の所得を意識する**:所得割は前年の所得をもとに計算されるので、収入が大きく変わった翌年は、保険料の変化にも備えておきたいところです。

また、今は会社員でも、将来独立や退職で国保に入る可能性は誰にでもあります。「会社員時代と国保で、保険料の感覚がこんなに違うのか」と驚かないよう、早めに仕組みを知っておくことをおすすめします。

## まとめ

今回の報道のポイントは次のとおりです。

- 医療分の年間上限額を3万円引き上げ、96万円とする方向で調整中とされている
- 目的は中間所得層の保険料負担の伸びの抑制とされている
- 影響を直接受けるのは、もともと上限に達している高所得世帯が中心とみられる
- 決定事項ではないため、今後の公表を確認することが大切
