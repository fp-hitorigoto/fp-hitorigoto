## 共通の方針

- **タイトルはクイズの問いをそのまま使う**。動画の1枚目と一致するので、
  スクロールを止めた理由がそのままタイトルになる
- 末尾に `【FP2級 ◯◯】` を付けて、検索と「自分向けだ」という判断を助ける
- **プラットフォームで変えるのは呼びかけの言葉だけ**（チャンネル登録／フォロー）
- ⚠️**AI開示の設定を全プラットフォームで忘れずに**

### ハッシュタグ（共通ベース）
```
#FP2級 #FP試験 #ファイナンシャルプランナー #歌で覚える #FP2級独学
```
- YouTube Shorts はこれに `#Shorts` を足す
- 曲ごとの分野タグ（#年金 #住宅ローン など）を1〜2個足す

## 14本ぶんの中身

### 1. My Decades, My Choice（年金受給）✅投稿済み（2026-11-10／4プラットフォーム）
- **タイトル**：繰上げ受給、1か月で何％減る？【FP2級 年金】
  ⚠️2026-11-10に「繰下げ・増える」から変更。**動画のカバー（Q1）と文面をそろえるため**
- **答え**：1か月0.4％減。繰下げなら1か月0.7％増
- **一言解説**：どちらを選んでも「あなたの正解」。増減率はセットで覚える
- **カバー画像**：動画の**4秒地点**（Q1のコマ）
- **分野タグ**：#年金 #老齢基礎年金
- **本編**：https://youtu.be/GJ2T2md0JDM

### 2. 20 Years, One Promise（加給年金）✅投稿済み（2026-11-11／4プラットフォーム）
- **タイトル**：加給年金が止まるのは配偶者が何歳？【FP2級 年金】
- **カバー画像**：動画の**4秒地点**（Q1のコマ）
- **答え**：配偶者が65歳になったとき。代わりに振替加算が始まる
- **一言解説**：加給年金がつくのは厚生年金20年以上。振替加算の額は生年月日で変わる
- **分野タグ**：#年金 #加給年金
- **本編**：https://youtu.be/2PNke7j7gmM

### 3. Balance（貸借対照表と損益計算書）✅投稿済み（2026-11-12／4プラットフォーム）
- **タイトル**：損益計算書の利益は何段階？【FP2級 財務諸表】
- **答え**：5段階（売上総→営業→経常→税引前当期純→当期純）
- **一言解説**：PLは一年の物語、BSは今この瞬間の姿
- **分野タグ**：#財務諸表 #決算書
- **本編**：https://youtu.be/8dOzPn5AzoM

### 4. Build Your Own Tomorrow（小規模企業共済）
- **タイトル**：小規模企業共済、掛金はどう扱われる？【FP2級】
- **答え**：全額が所得控除（小規模企業共済等掛金控除）
- **一言解説**：受け取れるのは廃業や退職のとき。役員・個人事業主のための備え
- **分野タグ**：#小規模企業共済 #所得控除
- **本編**：https://youtu.be/YBzn3aKsk4s

### 5. Carry the Light（中高齢寡婦加算）

- **分野タグ**：#遺族年金 #中高齢寡婦加算

### 6. Do The Math（6つの係数）
- **タイトル**：毎年積み立てて将来いくら？使う係数は【FP2級】

## 📁 カバー画像の置き場所

```

```

```bash
ffmpeg -ss 4 -i "<mp4>" -frames:v 1 "出力.png"
```

| 書き出した秒数 | 曲 |
|---|---|
| **4秒** | 01・02・03・06・07・08・09・10・11・12・13・14 |
| **2秒** | **04 Build Your Own Tomorrow／05 Carry the Light** |

⚠️**Q1が何秒地点かは曲ごとに違う。** 04と05は4秒だと**もうQ2に変わっていた**。
　全曲4秒と決めつけないこと。確認は**4秒のコマを並べた一覧画像**を作ると一度で済む。
```bash
ffmpeg -ss 4 -i "<mp4>" -frames:v 1 -vf scale=270:480 g<NN>.png   # 各曲
ffmpeg -pattern_type glob -i "g*.png" -filter_complex "tile=4x3" sheet.png
```
⚠️**答えのコマは選ばない**（一覧で答えが見えてしまう）。
