# 2級Vol.2 サムネイル 10〜15曲目（見本画像なし版）

## なぜ見本なし版を作ったか
10曲目で、見本として添えた9曲目のサムネイルが**そのまま複製されて返ってくる**問題が起きた
（Four Steps／生命保険料控除のまま出てくる）。「2枚目の文字は使わないでください」と明示しても直らなかった。
原因は**同じチャット内に前の画像があると参照し続けてしまう**こと。3級で「原則1ヶ月」が混入したのと同じ現象。

→ **新しいチャットを開き、添付は背景写真1枚だけ。レイアウトは言葉で指定する。**

## 使い方
1. **ChatGPTで新しいチャットを開く**（前の画像が残っているチャットは使わない）
2. 添付するのは**背景写真1枚だけ**
   `FP学習ソング２級/Vol2/バンド画像/FP2級_Vol2_バンド_16x9_サックスと寄りショット.png`
3. 下のプロンプトの `●` を曲ごとに差し替えて送る
4. **1曲ごとに新しいチャットを開く**（続けて頼むと前の絵に引きずられる）
5. 生成物はその場でダウンロード。保存先 `FP学習ソング２級/Vol2/サムネイル/`

## プロンプト本体（●を差し替える）

```
添付した1枚のライブ写真を背景に、YouTubeサムネイル（16:9・1920x1080）を作ってください。
写真の人物・ステージ照明・夕景のオレンジ色・スモークはそのまま活かし、
文字が読みやすいよう必要な範囲だけ暗く調整してください。
人物は引き加減のまま、拡大も縮小もしないでください。

■ 全体の配色
ゴールド（金）と白を基調。背景写真の琥珀色の夕景に合わせる。

■ 左上：ゴールドの縦長バッジ（画面の左上隅、幅は画面の約15%）
月桂樹の枝で左右を囲み、上に小さな王冠。金色の細い枠線。
中の文字を上から順に：
　FP2級         ← 両脇に小さな音符マーク
　学習ソングアルバム
　Vol.2         ← 一回り大きく
　リスク管理     ← 細いリボン状の帯の中に

■ 右上：フック（画面の右上、幅は画面の約45%）
黒い筆跡のような荒いブラシの帯を背景に敷く。
　上段（小さめ・白）：●フック小
　下段（特大・金色のメタリック、黒フチ）：●フック大
下段は画面で一番目立つ文字にしてください。

■ 下部：3行（画面下40%、中央ぞろえ）
　1行目（特大・白の明朝体系、黒フチ）：●英語タイトル
　2行目（大・金色のゴシック体、黒フチ、左右に細い金のラインを添える）：●日本語サブタイトル
　3行目（中・白のゴシック体、黒フチ）：●補足

■ 重要・日本語の表記
1文字も崩さないでください。特に次に注意：
　「学習ソングアルバム」（「アム」「プバム」にしない）
　「リスク管理」
　●注意語
```
