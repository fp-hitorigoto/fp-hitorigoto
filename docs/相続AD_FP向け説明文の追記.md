## 1. 足すのは十年、引くのは全部

```
▼FP試験の相続分野と重なります

このチャンネルは、もともとFP試験の学習ソングを公開しています。
相続アドバイザー2級の論点は、FP2級・1級の「相続・事業承継」と
重なるところが多く、どちらの対策にも使えます。

この曲で重なるのは、次の論点です。
・相続の承認と放棄（知った時から3か月）、限定承認は全員で
・遺留分の割合と、侵害額請求の期限（知った時から1年、開始から10年）
・自筆証書遺言の要件と、検認は有効無効を決めるものではないこと
・配偶者の税額軽減、2割加算、未成年者控除

▼歌で覚えるFP3級 Vol.6 相続・事業承継
https://www.youtube.com/playlist?list=PLes7WJbxNpJQ
```

・申告と納付は10か月、準確定申告は4か月、延納と物納
