# 新築マンションの投機的売買を税制で抑制？｜FPが押さえるべき短期売買課税と住宅購入の考え方

新築マンションの価格が高止まりしていますよね。「そろそろ買いたいけれど、今は様子見したほうがいいのかな」と迷っている方も多いと思います。

そんななか、政府・与党が2027年度の税制改正で、投機目的の短期売買を抑える税制上の措置を検討していると、NHKニュースが報じました。価格が高止まりするなか、短期的な売買が価格を押し上げる一因になっているという問題意識によるものです。

## 今わかっているのは「方向性」と、検討中の案

報じられているのは「投機的な取り引きを抑制する措置を検討している」という方向性です。ほかの報道では、購入した新築マンションに住まず1年以内に売却した場合などを念頭に、所得税などの課税強化が検討されていると伝えられています。自民党の部会も、所得税・法人税・不動産取得税などの課税強化を求める決議をまとめた、と報じられています。

ただ、具体的な税率や対象の範囲は、年末の与党税制改正大綱で決まる見通しで、まだ確認できていません。この段階で「自分は損をする」「得をする」と決めつけるのは早いですね。

## 土台になる、いまの譲渡所得課税

新しいルールを考えるうえで、まず今の仕組みを知っておくと役に立ちます。マンションを売って利益(譲渡所得)が出ると、所有期間によって税率が変わります。

- **短期譲渡所得**:売却した年の1月1日時点で所有期間が5年以下。所得税30%、住民税9%
- **長期譲渡所得**:同じ時点で5年超。所得税15%、住民税5%

このほか、所得税額に対して2.1%の復興特別所得税もかかります。

たとえば譲渡益が1,000万円なら、概算では次のとおりです。

- 短期:約396万円(実効税率で約39.63%)
- 長期:約203万円(実効税率で約20.315%)

短期で売ると、長期の倍近い税負担になります。すでに短期保有には重い税率がかかっているのですね。そのうえで何を上乗せ・強化するのかが、今後の焦点になりそうです。

なお、譲渡益は売却価格そのものではなく、購入費用や売却にかかった費用などを差し引いて計算します。自宅として住んでいた物件には、別の特例が用意されています。ただし要件があるので、実際に売るときは税務署や税理士などの専門家に確認してください。

## 「自分ごと」として考えてほしいこと

投機目的でない方にとって大切なのは、**「短期で売るつもりはなくても、売ることになる可能性はゼロではない」**という点です。

たとえば、こんな場面があります。

- 転勤や転職で住み替えが必要になった
- 家族構成が変わり、手狭になった
- 親の介護で住まいを見直すことになった

「ずっと住むつもり」で買っても、数年後に売ることになる方は珍しくありません。人生は計画どおりにいかないこともありますよね。

だからこそ、購入前に次の3点を確認しておくと安心です。

1. **無理のない返済計画か**:金利が上がっても家計が回るか、余裕を見ておきます。
2. **5年以内に売る可能性があるか**:転勤の可能性など、手放すシーンを一度想像してみます。
3. **売却時にいくら手元に残るか**:ローン残高、売却費用、税金を差し引いて考えます。

新築マンションは、購入後に価格が下がることもあれば、上がることもあります。「値上がりを期待して買う」という発想だけで動くと、税制が変わったときに計画が崩れてしまいます。「住む」ことを軸に選んでおくと、税制の変更に振り回されにくくなります。

## まとめ

今回の報道は、住宅購入を考える方にとって気になるニュースですね。ただ、今の段階では、具体的な税率や対象の範囲は決まっていません。報道を見て慌てて契約するのは避けたいところです。

まずは次のステップで整理しておきましょう。

- 今後の税制改正大綱で、どんな措置になるのかを確認する
- 自分が住むために買うのか、投資なのかを整理する
- 売却の可能性も含めて、資金計画を一度試算してみる

住まいは、人生で最も大きな買い物のひとつです。ニュースの動きに目を配りつつ、ご自身の暮らしに合った選択をしてくださいね。
