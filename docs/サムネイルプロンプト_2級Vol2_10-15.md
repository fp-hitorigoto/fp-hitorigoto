# 2級Vol.2 サムネイル 10〜15曲目

## ✅ 解決：**「生成前に文字を箇条書きで復唱させる」**（2026-11-04）

長く詰まっていた「見本画像がそのまま複製される」問題は、**復唱させる工程を1行入れるだけ**で解決した。
10〜15曲目の6枚を連続で生成し、**一度も複製が起きず、誤字もゼロ**。
数字5つ入る行も、英語タイトルのカンマも、半角大文字の「PL」も崩れなかった。

```
【手順】
画像を作る前に、上の6項目をそのまま箇条書きで復唱してください。
復唱した内容と1文字でも違う画像は作らないでください。
復唱が終わってから画像を生成してください。
```

**なぜ効くのか（推測）**：一度文字を言語化させると、前の画像から引っ張らなくなる。
「2枚目の文字は使わないでください」と禁止するだけでは効かなかった。

### 合わせて効いた書き方
- 前回の具体的な文字列を挙げて「一文字も使わないでください」と明示する
  （例：「前回の『Under the 80 Line』『比例てん補になるのは』といった文字は〜」）
- 「前回までと同じデザイン体裁・同じフォント・同じ人物の大きさで」と最初に書く

### 見本なし版も試したが、継続セッションのほうが良かった
新しいチャットで背景写真1枚だけ＋レイアウトを言葉で指定する方法も試した。
文字は正確に出たが、**フォントとバッジの体裁が微妙に違った**
（「学習ソングアルバム」が2行に折れる、バッジがやや縦長になる）。
→ **継続セッション＋復唱させる方式を正とする。**

## 使い方
1. **これまでのサムネイルを作ってきたチャットの続き**で依頼する
2. 下のテンプレートの `●` を差し替えて送る
3. 生成物はその場でダウンロード。保存先 `FP学習ソング２級/Vol2/サムネイル/`

## テンプレート

```
続けて●曲目のサムネイルを作ります。
前回までと同じデザイン体裁・同じフォント・同じ人物の大きさで作ってください。

ただし、文字は【すべて】下記に差し替えます。
前回の「●前回の英語タイトル」「●前回の日本語サブ」「●前回のフック小」
「●前回のフック大」といった文字は、一文字も使わないでください。

【今回入れる文字】
左上バッジ：FP2級／学習ソングアルバム／Vol.2／リスク管理（前回と同じ）
右上フック（小）：●
右上フック（大）：●
下部1行目：●英語タイトル
下部2行目：●日本語サブタイトル
下部3行目：●補足

【手順】
画像を作る前に、上の6項目をそのまま箇条書きで復唱してください。
復唱した内容と1文字でも違う画像は作らないでください。
復唱が終わってから画像を生成してください。

【表記の注意】
●曲ごとの注意語
```

### 14曲目は補足を歌詞に合わせて差し替えた
当初「住民税は上限2万5千円／支払保険料の全額が対象」としていたが、
**歌詞に住民税の話は出てこない**ことを確認して差し替えた。
この曲は「所得税の5万円」と「損害保険金の非課税（事業の営業補償・休業補償だけは課税）」の2本立て。
→ **サムネイルは中身の予告なので、歌っていない内容を書かない。**
