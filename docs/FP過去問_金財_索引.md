## 利用のルール（金財の公表内容）

https://products.kinzai.or.jp/exam-ginou/use-of-test-questions/

- 著作権は金財が持つ（2級・3級の学科はFP協会と共有）
- **申請は不要。出典を明記すれば利用できる**
- 修正・加工して使う場合は、その旨も明記する

出典の書き方（金財の掲載例）：
```
一般社団法人金融財政事情研究会 ファイナンシャル・プランニング技能検定 2級学科試験 2026年5月
```
加工した場合は末尾に「を一部改変」と付ける。

⚠️**クイズアプリの問題は自作であり、過去問そのものの転載ではない。**
　 それでも過去問を下敷きにした場合は、出典を書く。

## 中身について分かったこと

- **2級・3級のPDFは、問題と正解が1ファイルに入っている**（各問のあとに「正解」）
- 1級学科は「基礎編」「応用編」「模範解答」が別ファイル
- 各PDFの冒頭に**法令基準日**が書かれている
  例：2026年5月公表分の2級学科 →「2025年4月1日現在施行の法令等」

## 出題実績の調べ方

### 1. テキスト検索（手元・確実）

```bash
cd ~/Downloads/FP過去問_金財/_text
grep -c "区分所有" FP2級*_g_*.txt        # 回ごとのヒット数
grep -l "労働者災害補償保険" FP2級*_g_*.txt  # 登場した回
```

⚠️**手元にあるのは5回分（2級学科）**なので、これだけで頻度は判断できない。
　 傾向を見るには次の分野別索引と併用する。

https://fp2-siken.com/lifeplan.html など6分野。論点名ごとに出題回が並ぶ。
