# TOPIXの中身が初めて入れ替わりました。持っている投資信託への影響は？

2026年10月30日、TOPIX（東証株価指数）の構成銘柄が、新しいルールで初めて入れ替わりました。

TOPIXは、日本株全体の動きを示す代表的な指数です。新NISAで「国内株のインデックスファンド」を持っている方の多くは、このTOPIXに連動する商品を選んでいるのではないでしょうか。

「指数の中身が変わる」と聞くと、自分の投資信託にも影響があるのか、気になりますよね。落ち着いて、何が変わったのかを整理してみましょう。

■ 先に結論：慌てる必要はありません

今回のポイントは3つです。

・選ばれる対象が広がりました（これまでのプライム市場に加えて、スタンダード市場・グロース市場の銘柄も対象に）
・売買の活発さを基準に、入れ替えが判断されます
・外れる銘柄は、すぐには消えません

最後の点が、持っている方にとっていちばん大切なところです。

■ 何がどれだけ入れ替わったのか

JPX総研（日本取引所グループ）が10月7日に結果を公表しています。報じられている内容は、こうです。

・新しく採用された銘柄：35銘柄（スタンダード市場から23、グロース市場から12）
・基準を満たさなかった銘柄：683銘柄（「移行措置銘柄」といいます）
・基準を満たした銘柄：986銘柄

この683銘柄は、いきなりTOPIXから外れるわけではありません。2028年7月まで、四半期ごとに8回に分けて、少しずつウエイトを下げていく仕組みです。2028年7月末にゼロになる予定とされています。

つまり、持っているファンドの中身が、ある日突然ガラッと変わるわけではない、ということですね。

なお、TOPIXの銘柄数は「結局いくつ？」と思われるかもしれません。報道によって数字が違いますが、これは何を数えているかが違うためです。

・入れ替え前：1,634〜1,636銘柄
・10月末の時点（移行措置の銘柄を含む）：1,669銘柄
・移行がすべて終わったあと：986銘柄の見通し

■ そもそもTOPIXって？日経平均とは何が違うの？

ニュースでは「日経平均」と並んで出てきますが、性格が違います。

TOPIXは、会社の「大きさ」（時価総額）を基準にした指数です。大きな会社ほど、指数への影響が大きくなります。対象も多く、日本株の「全体像」を映します。算出しているのはJPX総研です。

日経平均は、東証プライム市場の代表的な225銘柄を対象に、株価をもとに計算した指数です。株価の水準が高い銘柄の動きに、左右されやすい特徴があります。日本経済新聞社が算出しています。

どちらが良い、悪いではありません。日本株の全体像を見たいときはTOPIX、よく報道される指標として日経平均、というイメージで使い分けるとわかりやすいと思います。

■ 持っているファンドはどうなる？

TOPIXに連動するファンドは、指数の構成に合わせて、持っている銘柄を調整していきます。ただ、先ほどお話しした移行措置のおかげで、急に大きく入れ替わることはありません。

気になる方は、持っている投資信託の「運用レポート」を開いてみてください。どの銘柄をどれくらい持っているかが載っています。

もうひとつ、確認しておきたいのが「国内株に偏っていないか」です。TOPIXは日本株の指数なので、これだけで積み立てていると、投資先は日本に集中します。海外の株式などと組み合わせることも、選択肢のひとつです。

■ 新NISAで確認しておきたいこと

TOPIXに連動する商品でも、つみたて投資枠の対象になっているかどうかは、商品によって異なります。金融庁の公表リストで、確認してみてください。

あわせて、コストも見ておきましょう。同じTOPIX連動でも、信託報酬（保有している間ずっとかかる手数料）は商品ごとに違います。目論見書に載っています。

■ まとめ

・10月30日、新ルールで初めてTOPIXの銘柄が入れ替わりました
・外れる銘柄のウエイトは、2028年7月まで段階的に下がります。慌てる必要はありません
・持っているファンドの「運用レポート」を、一度開いてみましょう
・国内株に偏りすぎていないか、コストはどうかも確認しておくと安心です

指数の仕組みを知っておくと、ニュースを見ても落ち着いて受け止められます。この機会に、ご自身の持ち物を覗いてみてくださいね。

なお、本記事は特定の商品の売買を勧めるものではありません。投資の判断は、ご自身の状況に合わせて行ってください。
