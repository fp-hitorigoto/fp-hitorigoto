# EV・PHEVの「CEV補助金」は家計にどう効く？｜FPが押さえるべき車購入の総額の考え方と補助金の注意点～補助額の決まり方・受給までの流れ・車両価格と維持費で見る損益分岐～

「補助金が出るから、EVにしたら得なのかな?」

車の買い替えを考えるとき、こんな疑問を持つ方は多いのではないでしょうか。物価高で家計の見直しが進むなか、補助金を調べるところから検討を始める方も増えているようですね。

今回は、EVやPHEVなどを買う人向けの国の補助金「CEV補助金(クリーンエネルギー自動車導入促進補助金)」を、家計の目線で考えてみます。

## 補助金は「値引き」であって「得の保証」ではない

先に結論です。補助金は車両の購入負担を軽くしてくれるものですが、買えば得になる仕組みではありません。

補助金が効くのは、購入時の1回だけです。一方で、車は購入後も何年も、ガソリン代や電気代、保険料、税金、車検、バッテリーの状態などに付き合っていくものです。

「いくら補助が出るか」より「何年乗って、トータルでいくらかかるか」を見るのが、FPとして一番お伝えしたい視点です。

## 補助額と受給までの流れ

補助額は、EV、軽EV、PHEV、FCVといった区分ごとに上限が決まっていて、年度ごとに見直されます。実際の額は、車種ごとに公表されている一覧で決まるとされています。同じEVでも車種によって金額が違うので、「EVなら一律いくら」とは考えないでください。最新の金額や対象車種は、購入前に必ず公式の情報で確認しましょう。

直近では、経済産業省が2026年10月21日に、2027年1月以降の登録分について補助額を現在の6〜8割程度に引き下げる見直しを発表したと報じられています。また、補助金は先着順で、受付の終了は2026年12月上旬〜下旬が見込みと公表されています(申請状況で前後します)。購入を考えている方は、登録の時期で補助額や受給の可否が変わる可能性があるので、販売店や公式サイトで最新の条件を確認してください。

流れは、おおまかに次のとおりです。

1. 対象車種を選んで、販売店で契約する
2. 車を登録(納車)する
3. 申請する(販売店経由が一般的)
4. 審査を経て交付が決まり、振り込まれる

つまり、補助金は車を買った後に受け取るお金です。購入時には、いったん全額を支払う前提で資金計画を立てておくほうが安心ですね。

## 見落としがちな3つの注意点

**① 予算に限りがある**
申請額が予算に達すると、受付が早く終わる可能性があります。「補助金を前提に購入計画を立てたのに、間に合わなかった」という事態は避けたいところです。

**② 申請期限がある**
登録後の申請期限が定められています。販売店が手続きを手伝ってくれるのが一般的ですが、期限は自分でも確認しておくと安心です。

**③ 保有義務がある**
補助を受けた車は、一定の期間(処分制限期間)のあいだ、売却や譲渡が原則として制限されます。期間は区分や年度で異なるため、要確認です。

家族が増える、転勤で車が不要になる、数年で乗り換えたい。こうした可能性がある方にとって、この制限は意外と大きな制約になります。「補助金をもらう代わりに、しばらくはその車と付き合う約束をする」くらいの感覚でいるとよいかもしれません。

## 損得は「総額」で比べてみる

では、どう比べればよいのでしょうか。考え方はシンプルです。

**(車両価格 − 補助金)+ 保有期間中の維持費 − 手放すときの価値**

これを、候補の車ごとに並べて比べます。たとえば、ガソリン車とEVで迷っているなら、次のような点を確認します。

- 車両価格の差は、補助金でどこまで縮まるか
- 燃料代と電気代の差はどのくらいか
- 自宅で充電できるか(充電設備の設置費用がかかる場合もあります)
- 税金や保険料に違いはあるか
- 数年後に売るとき、どのくらいの価値が見込めるか

ここで大切なのは、充電環境によって結果が変わりやすいことです。自宅で充電できる人と、外出先の充電に頼る人とでは、電気代の感覚がかなり違ってきます。同じEVでも、暮らし方によって損得の方向が変わる点には注意してください。

また、自治体によっては独自の補助や、税制面の優遇が用意されている場合もあるとされています。こちらも、お住まいの地域や年度によって異なるため、確認してみてくださいね。

## 「いつ元が取れるか」より「無理なく持てるか」

「何年乗れば元が取れる?」というのは、誰もが気になるところです。ただ、燃料代や電気代の水準、走行距離、売却時の価値は、将来どうなるか分かりません。ですので、元が取れる年数をぴったり当てにいくのは、あまり現実的ではないと思っています。

それよりも、次の2点を考えてみてください。

- 補助金がなくても、無理なく買える金額か
- 保有義務の期間、その車に乗り続けても生活に支障がないか

補助金は、もらえたらありがたい「おまけ」くらいに考えるのが、家計にとっては安全です。補助金ありきで背伸びをした購入は、かえって家計を苦しくしかねません。

## まとめ

- CEV補助金は車両価格を下げてくれるが、買えば得になるわけではない
- 補助額は車種ごとに異なり、年度で見直される
- 予算・申請期限・保有義務の3点は必ず確認する
- 損得は、車両価格・維持費・保有期間・売却価値の「総額」で比べる
- 充電環境や暮らし方によって、結論は変わる

車は、家計の中でも大きな買い物のひとつです。補助金の金額だけで決めず、ご自身の暮らしに合うかどうかをじっくり考えてみてくださいね。

※制度の内容は年度によって変わります。最新の情報は、公式の案内や販売店で必ずご確認ください。
