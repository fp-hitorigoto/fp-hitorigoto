# 作業手順（YouTube Studio）

1. YouTube Studio → 左メニュー「コンテンツ」
2. 検索窓に曲名の一部（例：`失業`）を入れて絞り込む
3. 動画にカーソルを合わせて、鉛筆アイコン（詳細）をクリック
4. 「説明」欄の**いちばん上**に訂正文を貼り、1行空けてから既存の本文を続ける
5. 右上の「保存」をクリック

> ⚠️ **説明欄の先頭に入れること**。YouTubeは最初の2〜3行しか表示せず、それ以降は「もっと見る」を押さないと読まれない。訂正は押さなくても見える位置に置く。

## 固定コメントの付け方（1本目のみ）

1. 動画の公開ページを開く
2. 自分のアカウントでコメントを投稿する
3. 投稿したコメントの「︙」→「固定」→「固定」で確定

# ① 失業じゃない、求職だ！〜雇用保険の真実〜（Vol.1・7曲目）

**誤り**：「自己都合 2ヶ月の給付制限」→ 2025年4月の改正で**原則1ヶ月**に短縮。
あわせて「待期期間 ここが違う」も不正確（待期7日は自己都合・会社都合に共通。変わるのは給付制限）。

## 説明欄の冒頭に貼る

```
【訂正とお知らせ】
歌詞の「自己都合 2ヶ月の給付制限」は、2025年4月の法改正により
現在は「原則1ヶ月」に短縮されています。

また、待期期間7日は自己都合・会社都合に共通です。
自己都合か会社都合かで変わるのは、待期ではなく給付制限のほうです。

最新の制度はハローワーク等の公的機関でご確認ください。
```

## 固定コメントに貼る

```
【訂正】歌詞中の「自己都合 2ヶ月の給付制限」は、2025年4月の法改正で
現在は「原則1ヶ月」に短縮されています。
また、待期期間7日は自己都合・会社都合とも共通で、
退職理由によって変わるのは給付制限のほうです。
失礼しました。最新の制度は公的機関でご確認ください。
```

# ② 配偶者の壁〜１３６万・１６９万・２０７万〜（Vol.4・5曲目）

**誤り**：「169万円は 社会保険の壁」→ 社会保険の壁は**106万円・130万円**。
169万円は配偶者特別控除が満額38万円を維持できる上限であり、社会保険とは無関係。

> タイトルの3つの数字（136万・169万・207万）と、歌詞中の基礎控除104万円は令和8年分として正しい。
> 誤っているのはBridgeのこの1行だけ。

## 説明欄の冒頭に貼る

```
【訂正】
歌詞の「169万円は社会保険の壁」は誤りです。
社会保険の壁は106万円・130万円です。
169万円は、配偶者特別控除が満額38万円を維持できる上限の額です。

タイトルの136万・169万・207万は、いずれも税金（配偶者控除・
配偶者特別控除）の区切りです。社会保険の基準とは別に判定されます。
```

# ③ 分けて守れ〜ポートフォリオ理論〜（Vol.3・4曲目）

**誤り**：「０に近いほど 分散の効果大」→ 正しくは**マイナス1に近いほど**。
なお、同じ曲のサビ（「相関係数 低いほど分散効果」）とアウトロ（「マイナス１が 理想の分散」）は正しい。

## 説明欄の冒頭に貼る

```
【補足】
歌詞の「0に近いほど分散の効果大」は、正しくは
「マイナス1に近いほど効果が大きい」です。

サビとアウトロで歌っているとおり、相関係数が低いほど
（マイナス1に近いほど）分散投資の効果は高まります。
```
