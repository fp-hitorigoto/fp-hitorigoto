不動産。**確定歌詞との照合済み**（2026-11-22）。`✅照合` が根拠。

## 🎯 フックの選び方
**「正しいこと」ではなく「受験生が間違えやすいこと」を書く。**
基準は ①引っかけられやすい ②理解しにくい ③混同しやすい。
書き方は「〜は〇〇である」より「**〜でも〇〇のまま**」「**〜だけは違う**」。
→ 詳しくは `docs/サムネイルプロンプト_2級Vol4.md` の冒頭。

#### 確認の結果（この曲のサムネイルはこのまま作ってよい）

| | 改正後（2026年4月1日施行） |
|---|---|
| **建替え決議（62条）** | 区分所有者・議決権の各**5分の4以上**。⚠️**出席者ベースではなく全体**。耐震性不足など一定の場合は4分の3 |
| 規約の設定・変更・廃止（31条） | 過半数の出席を前提に、**出席した**区分所有者・議決権の各4分の3以上 |
| 共用部分の重大変更（17条） | 同上 |
| 普通決議（39条） | **出席者**の各過半数 |

→ **フック「建替えに必要なのは 5分の4」は改正後も正しい。** そのまま使える。
→ ⚠️**3行目は「出席者の4分の3」に直した。** 改正で「全体の3/4」から変わったため。

📌**歌詞は「四分の三の 規約変更」とだけ歌っている。** 間違いではないが、
　 受験生が「全体の3/4」と覚える余地がある。**動画の説明文で「出席者の」を補う。**
