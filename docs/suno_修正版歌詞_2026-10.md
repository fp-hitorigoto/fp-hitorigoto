# 1. 2級 Vol.1・12曲目「Do The Math 〜6つの係数、使いこなす力〜」

## 直した理由

Bridgeで、減債基金係数を「ゲン（現在）」、資本回収係数を「シ（将来）」に分類していたが**逆**だった。

- 資本回収係数：今ある元手から毎年の受取額を出す → **現在側**
- 減債基金係数：将来の目標額から毎年の積立額を出す → **将来側**

音の語呂（ゲン／シ）と中身が逆になる2つなので、最終行の「音でも見分けられるんだ」も成り立たない。

## Before → After（Bridgeのみ）

**Before**
```
現価、減債、年金現価
ゲン！ゲン！ゲン！
終価、年金終価、資本回収
シ！シ！シ！
「ゲン」は現在、「シ」は将来
音でも見分けられるんだ
```

**After**
```
現価、資本回収、年金現価
ゲン！ゲン！ゲン！
終価、減債基金、年金終価
シ！シ！シ！
「ゲン」は現在、「シ」は将来
持っている今か、先の未来か
```

> ⚠️ 残る論点：「ゲン！ゲン！ゲン！」の3回は、現価・年金現価の2つしか音が合わなくなる。チャントの勢いを優先してこのままにするか、別案にするかは要判断（後述の代替案を参照）。

# 2. 2級 Vol.2・13曲目「Home or Away 〜傷害保険と個人賠償責任保険、境界のパターン〜」

## 直した理由

Verse 3の最終行「国内旅行傷害保険には この補償がない」が**逆**だった。

- 国内旅行傷害保険：細菌性・ウイルス性の食中毒を**補償する**
- 海外旅行傷害保険：同じく補償する
- 補償しないのは**普通傷害保険**

Verse 1で普通傷害保険を歌っているので、そこへの対比に直せば自然につながる。

> Chorus の「国内はダメ、海外はいい／地震・噴火・津波の…」は**地震等の話なので正しい**。触らない。

## Before → After（Verse 3のみ）

**Before**
```
海外旅行傷害保険には もう一つ強みがある
細菌性の食中毒も ウイルス性の食中毒も
ちゃんと対象に 入っている
国内旅行傷害保険には この補償がない
```

**After**
```
旅行傷害保険には もう一つ強みがある
細菌性の食中毒も ウイルス性の食中毒も
ちゃんと対象に 入っている
普通傷害保険には この補償がない
```

変更は1行目の「海外」を取ることと、4行目の「国内旅行傷害保険」→「普通傷害保険」の2箇所だけ。

# 3. 2級 Vol.5・3曲目「1,000 and 10,000 〜街の輪郭を決める線〜」

## 直した理由

Verse3で、準都市計画区域の開発許可の面積基準を10,000㎡としていたが、正しくは**3,000㎡以上**。
さらに、同じく3,000㎡以上の**非線引き都市計画区域**（区域区分が定められていない都市計画区域）が抜けていた。

正しい区分：

| 区域 | 開発許可が必要な規模 |
|---|---|
| 市街化区域 | 1,000㎡以上 |
| 市街化調整区域 | 面積に関係なく必要 |
| 非線引き都市計画区域 | 3,000㎡以上 |
| 準都市計画区域 | 3,000㎡以上 |
| 区域外 | 10,000㎡以上 |

> Chorus・Final Chorus の「市街化区域は 千平米／区域の外は 一万平米」は**正しい**ので触らない。タイトル「1,000 and 10,000」もそのまま。

## Before → After（2箇所）

**Before**
```

準都市計画 その先も
一万平米 それ以上なら
開発許可が 必要になる
```

**After**
```

準都市計画区域も 三千平米
どちらでもない 区域の外は

開発許可が 必要になる
```
