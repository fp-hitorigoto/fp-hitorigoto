## 共通テンプレート

以下の `●` の部分だけを曲ごとに差し替える。

```
2枚目の画像は、同じシリーズの前の曲のサムネイルです。
このデザイン体裁を厳密に踏襲して、1枚目のライブ写真から
●曲目のサムネイルを作ってください。16:9の横長です。

【左上】
前の曲とまったく同じゴールドバッジを配置してください。
　FP2級
　学習ソングアルバム
　Vol.1
　ライフプランニングと資金計画

【右上のフック】
　小さく：●
　大きく金色で：●

【下部の3行】
　1行目（大・白）：●
　2行目（中・金色）：●
　3行目（小・白）：●

写真の人物・ステージ照明・スモークの雰囲気はそのまま活かし、
文字が読みやすいよう必要な範囲でのみ暗く調整してください。
人物の大きさ・位置は2枚目と同じ引き加減にしてください。

【重要・文字の正確性】
日本語の表記を1文字も崩さないでください。特に次に注意：
　「学習ソングアルバム」（「アム」「プバム」にしない）
　「ライフプランニング」（「ライフブランニング」にしない）
　●（曲ごとの注意語）
```

# 8. Pay It Down 〜住宅ローン、返し方という戦略〜

| 項目 | 内容 |
|---|---|
| フック小 | 利息を減らすなら |
| フック大 | 期間短縮型 |
| 1行目 | Pay It Down |
| 2行目 | 住宅ローン、返し方という戦略 |
| 3行目 | 総返済額は元金均等が少ない／フラット35の団信は任意 |
| 注意語 | 「Pay It Down」／「元金均等」（「元利均等」と取り違えない）／「団信」はこの2文字のまま |
| 保存名 | `FP2_Vol1_08_住宅ローン.png` |

**この回は数字より対比が中心**（期間短縮型／返済額軽減型、元利均等／元金均等）。
**「元金均等」と「元利均等」は一字違いで意味が逆**になるので、生成後は3行目を重点確認。
