# PR用ショート 台本（アプリの実演）

作成日：2026-11-23

**目的**：クイズ・用語集アプリを知ってもらう。既存の劇場型ショート（曲が主役）とは別の型で、
**アプリの画面そのものを見せる。**

| | |
|---|---|
| 長さ | 15〜20秒 |
| 形式 | 1080×1920（縦）・音なしでも読める焼き込み字幕 |
| 誘導先 | https://fp-hitorigoto.github.io/fp-hitorigoto/apps/ |
| 検索ワード | 「歌で覚えるFP」 |

⚠️**まず1本だけ作って反応を見る。** 6本作ってから効かないと分かるのが一番もったいない。

## 問題の選び方（ここが肝）

| 基準 | 理由 |
|---|---|
| **仕組みを問う。金額を問わない** | ショートは消さない限り残る。金額は改正で古くなる |
| **間違えやすいものを選ぶ** | 「正しいこと」より「勘違いしていること」のほうが止まる |
| 検索需要の大きい分野（税金・相続・年金） | |

### ⚠️ 基礎控除（問46）は採用しなかった

「48万円 → 58万円」は改正の目玉で引きは強いが、**2026年12月1日から104万円になる。**
試験の法令基準日（2026年4月1日）では58万円が正解なので**アプリの中身は正しい**が、
ショートは残り続けるため、**動画のほうが先に古くなる。**

## 1本目：生前贈与加算（相続・事業承継）

出典：FP3級クイズ 問116。2024年1月以降の贈与から3年→7年（2031年1月に完全適用）。

### 構成

| 秒 | 画面 | 字幕（焼き込み） |
|---|---|---|
| 0〜2 | 黒地 → アプリの画面がフェードイン | **生前贈与、まだ「3年」だと思ってませんか？** |
| 2〜5 | アプリの問題文を表示 | 相続開始前、何年以内の贈与が加算される？ |
| 5〜8 | 選択肢4つ。カウント **3 → 2 → 1** | （カウントのみ） |
| 8〜11 | タップ → 正解が緑に光る | **答え：7年以内** |
| 11〜15 | 解説をゆっくりスクロール | 延長された4年分は、合計100万円を引いて加算 |
| 15〜18 | 🎵リンクが画面に出る瞬間 | **この分野は歌でも覚えられます** |
| 18〜20 | ロゴ＋URL | **無料・登録なし／「歌で覚えるFP」で検索** |

### 字幕の注意

- **1行は最大15文字程度**。スマホで2行に折れると読み切れない
- 0〜2秒の問いかけが命。ここで止まらなければ残りは見られない
- 「7年」は**大きく、他より目立たせる**

### ⚠️ 内容の裏取り

- 根拠：相続税法19条、令和5年度税制改正。国税庁 No.4161
- **「2024年1月1日以降の贈与から」**が前提。それ以前の贈与は3年のまま
- **段階的に適用**。2031年1月以降の相続で完全に7年になる
→ 字幕で「7年」と言い切ってよいが、解説のコマで**段階施行に触れる**こと

## 作り方

### 1. 画面収録

1. ブラウザの幅を**430px**にする（スマホの見え方にそろえる）
2. アプリを開く → QuickTime Player → 新規画面収録 → ブラウザの中身だけを範囲指定
3. **ゆっくり操作する。** 実際の指の速さだと、見ている側は読めない
4. タップの瞬間に0.5秒ためると、正解の緑が効く

### 2. 縦型に変換

```bash
ffmpeg -i rec.mov -vf "scale=1080:-2:flags=lanczos,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=0x0f1923" \
  -r 30 -c:v libx264 -crf 20 -pix_fmt yuv420p PR_01_生前贈与加算.mp4
```

背景色 `#0f1923` は用語集アプリの地の色。クイズアプリに合わせるなら `#1a365d`（ネイビー）。

### 3. 字幕

CapCutで載せる。**既存の劇場型ショートと同じ書体・配色**にそろえること。

### 4. カバー画像

既存のショートサムネイルと同じ作り方（1080×1920）。
⚠️**Xはカバーを設定できない**（最初のコマが使われる）ので、**0秒目を絵として成立させる。**

# 【確定】1本目：遺留分（2026-11-23 収録）

素材：`~/Downloads/PR用ショート試作/PR試作_iPhone_遺留分_v6.mp4`（21.8秒・1080×1920・音なし）

⚠️**台本の1本目を「生前贈与加算」から「遺留分」に変更した。**
　 iPhoneで収録したところ、ランダム出題で遺留分が出たため。遺留分も実績9回の定番で、
　 **「兄弟姉妹に遺留分はない」は間違えやすい**のでフックとして強い。

## 収録のしかた（実際にやった手順）

1. iPhone SEのSafariで `fp3-quiz.vercel.app` を開き、**「ホーム画面に追加」**
2. ホーム画面のアイコンから起動（⚠️これでSafariのバーが消え、アプリのように映る）
3. おやすみモード・マイクオフ・縦固定で画面収録
4. 相続 → 5問 → スタート → 1問解いて解説まで
5. AirDropでMacへ

### ⚠️ 収録で気をつけること（今回の反省）

| 起きたこと | 対策 |
|---|---|
| **冒頭0〜2秒にiPhoneのホーム画面が映った**（壁紙・LINEの未読件数・Dock） | **アプリを開いてから収録を始める**。または冒頭2.3秒を捨てる |
| 画面上部の**ステータスバーが赤くなる**（収録中の表示） | 上44px（750×1334基準）を切り落とす |
| 問題を表示したまま**10秒止まっていた** | 読む時間は6秒で十分。長い分はカットする（静止画面なのでつなぎ目は見えない） |

### 編集に使ったコマンド

```bash
# 赤いバーを切る → 1080×1920へ → 上下に濃紺の帯
ffmpeg -i 収録.MP4 -vf "crop=750:1290:0:44,scale=1080:-2:flags=lanczos,\
pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=0x0f1923,fps=30" -an -c:v libx264 -crf 20 出力.mp4
```

## 字幕の割り（実測・均等割りではない）

⚠️**秒数は動画を1コマずつ見て測った。** 推測で割らないこと（[[project-video-caption-workflow]]）。

| 秒 | 画面で起きること | 字幕 |

## 中身の裏取り

- 遺留分＝**兄弟姉妹以外**の相続人（配偶者・子・直系尊属）に保証された最低限の取り分（民法1042条）
- 総額の割合：直系尊属のみが相続人なら**1/3**、それ以外は**1/2**
- 2019年の改正で**金銭債権化**（遺留分侵害額請求権）
- 出題実績：fp3-siken.com「遺留分の金額」11回ほか

## BGM（2026-11-23〜24）

素材：`~/Downloads/PR用ショート試作/BGM_遺留分_21.8秒.m4a`（原音・前後フェードつき）
元曲：**FP3級 Vol.6「最低限の権利〜遺留分の壁〜」**（動画と同じ遺留分の曲）

### 区間の決め方

⚠️**音量では盛り上がりを見つけられない。** Sunoの曲は均されていて、
　 1秒ごとのRMSを測っても全編 -19〜-21dB でほぼ一定だった。
→ **LRC_auto（Whisperの実測タイミング）の歌詞位置**で決める。
　 ⚠️`LRC/` のほうは均等割り（5.08秒ずつ）なので使わない。

### 🚨 サビが「答え」になっている場合の合わせ方

この曲のサビは「**兄弟姉妹に 遺留分はないよ**」＝**クイズの答えそのもの**。
頭から流すと、考えてもらう前に答えが聞こえてしまう。

→ サビが鳴るのが**動画12.96秒（「答えは1番」が出る瞬間）**になるよう開始位置をずらした。
　 曲の **1:17.8〜1:39.6** を使用。

| 動画の時間 | 歌詞 |
|---|---|
| 0〜3秒 | 知った日から　一年しかない |
| 4〜8秒 | 相続開始から　十年で消える |
| 8〜13秒 | 過ぎたらそれで　終わりになるんだ |
| **13秒** | **兄弟姉妹に　遺留分はないよ** ← 答えの表示と同時 |
| 17〜21秒 | 二分の一か　三分の一か |

📌**歌詞が内容を言ってしまう曲をBGMにするときは、鳴る位置を答えに合わせる。**
