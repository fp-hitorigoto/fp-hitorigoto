# PR用ショート 台本（アプリの実演）

作成日：2026-11-23

**目的**：クイズ・用語集アプリを知ってもらう。既存の劇場型ショート（曲が主役）とは別の型で、
**アプリの画面そのものを見せる。**

| | |
|---|---|
| 長さ | 15〜20秒 |
| 形式 | 1080×1920（縦）・音なしでも読める焼き込み字幕 |
| 誘導先 | https://fp-hitorigoto.github.io/fp-hitorigoto/apps/ |
| 検索ワード | 「歌で覚えるFP」 |

⚠️**まず1本だけ作って反応を見る。** 6本作ってから効かないと分かるのが一番もったいない。

## 問題の選び方（ここが肝）

| 基準 | 理由 |
|---|---|
| **仕組みを問う。金額を問わない** | ショートは消さない限り残る。金額は改正で古くなる |
| **間違えやすいものを選ぶ** | 「正しいこと」より「勘違いしていること」のほうが止まる |
| 検索需要の大きい分野（税金・相続・年金） | |

### ⚠️ 基礎控除（問46）は採用しなかった

「48万円 → 58万円」は改正の目玉で引きは強いが、**2026年12月1日から104万円になる。**
試験の法令基準日（2026年4月1日）では58万円が正解なので**アプリの中身は正しい**が、
ショートは残り続けるため、**動画のほうが先に古くなる。**

## 1本目：生前贈与加算（相続・事業承継）

出典：FP3級クイズ 問116。2024年1月以降の贈与から3年→7年（2031年1月に完全適用）。

### 構成

| 秒 | 画面 | 字幕（焼き込み） |
|---|---|---|
| 0〜2 | 黒地 → アプリの画面がフェードイン | **生前贈与、まだ「3年」だと思ってませんか？** |
| 2〜5 | アプリの問題文を表示 | 相続開始前、何年以内の贈与が加算される？ |
| 5〜8 | 選択肢4つ。カウント **3 → 2 → 1** | （カウントのみ） |
| 8〜11 | タップ → 正解が緑に光る | **答え：7年以内** |
| 11〜15 | 解説をゆっくりスクロール | 延長された4年分は、合計100万円を引いて加算 |
| 15〜18 | 🎵リンクが画面に出る瞬間 | **この分野は歌でも覚えられます** |
| 18〜20 | ロゴ＋URL | **無料・登録なし／「歌で覚えるFP」で検索** |

### 字幕の注意

- **1行は最大15文字程度**。スマホで2行に折れると読み切れない
- 0〜2秒の問いかけが命。ここで止まらなければ残りは見られない
- 「7年」は**大きく、他より目立たせる**

### ⚠️ 内容の裏取り

- 根拠：相続税法19条、令和5年度税制改正。国税庁 No.4161
- **「2024年1月1日以降の贈与から」**が前提。それ以前の贈与は3年のまま
- **段階的に適用**。2031年1月以降の相続で完全に7年になる
→ 字幕で「7年」と言い切ってよいが、解説のコマで**段階施行に触れる**こと

## 作り方

### 1. 画面収録

1. ブラウザの幅を**430px**にする（スマホの見え方にそろえる）
2. アプリを開く → QuickTime Player → 新規画面収録 → ブラウザの中身だけを範囲指定
3. **ゆっくり操作する。** 実際の指の速さだと、見ている側は読めない
4. タップの瞬間に0.5秒ためると、正解の緑が効く

### 2. 縦型に変換

```bash
ffmpeg -i rec.mov -vf "scale=1080:-2:flags=lanczos,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=0x0f1923" \
  -r 30 -c:v libx264 -crf 20 -pix_fmt yuv420p PR_01_生前贈与加算.mp4
```

背景色 `#0f1923` は用語集アプリの地の色。クイズアプリに合わせるなら `#1a365d`（ネイビー）。

### 3. 字幕

CapCutで載せる。**既存の劇場型ショートと同じ書体・配色**にそろえること。

### 4. カバー画像

既存のショートサムネイルと同じ作り方（1080×1920）。
⚠️**Xはカバーを設定できない**（最初のコマが使われる）ので、**0秒目を絵として成立させる。**
