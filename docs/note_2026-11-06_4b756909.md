# アベノミクスは家計と投資に何を残したか｜FPが押さえるべき金融政策・円安・株高の関係と新NISAが生まれた背景

# アベノミクスは家計と投資に何を残したか

金利や為替が大きく動くたびに、「そういえばアベノミクスって何だったんだろう」と振り返る人は多いようです。今日は難しい制度の話はひとまず置いて、私たちの家計や投資にどうつながっているのかを、ひとりごとのように整理してみます。

■ 三本の矢と、異次元緩和という大きな一手

アベノミクスは、2012年12月に発足した第2次安倍内閣の経済政策です。柱は「大胆な金融政策」「機動的な財政政策」「民間投資を喚起する成長戦略」の三本の矢でした。

市場への影響が特に大きかったのは、一本目の金融政策です。2013年4月に日銀が「量的・質的金融緩和」、いわゆる異次元緩和を導入しました。物価上昇率2%を、2年程度で達成するという目標を掲げたものです。その後、2016年1月にはマイナス金利政策、同年9月には長短金利操作が加わりました。マイナス金利が解除されたのは2024年3月です。

約11年にわたる緩和路線でしたが、2%目標がすぐには実現しなかったことは押さえておきたいところです。政策全体の評価は、今も分かれています。

■ 円安と株高、あなたにはどちらの顔に見えますか

政権発足前後の2012年末は、ドル円が80円台、日経平均が1万円前後でした。その後ドル円は2015年に120円台まで円安が進み、日経平均も同年4月に約15年ぶりの2万円台を回復しています。

金融緩和が円安や株高の追い風になったと、一般には説明されています。ただ、円安の影響は立場によって変わります。

・輸出企業は、海外で稼いだお金を円に換えたときの金額が増えやすい
・輸入に頼る品物は、値段が上がりやすい
・外貨建ての資産を持つ人は、円での評価額が増えやすい

同じ円安でも、会社員、経営者、投資家、年金生活の方では感じ方が違いますよね。「円安は良い」「円安は悪い」と一括りにしないことが大切です。

■ 家計に残ったもの：低金利と「貯蓄から投資へ」

家計への影響で大きかったのは、低金利が長く続いたことだと思います。マイナス金利が解除される前の2024年3月ごろまでは、普通預金の金利は0.001%という水準でした。預金は安全ですが、利息はほとんど増えない。そう実感していた方も多いのではないでしょうか。

なお、足元の状況は大きく変わっています。日銀はマイナス金利を解除したあと、段階的に利上げを進め、2026年9月には政策金利を1.25%程度へ引き上げました。3メガバンクの普通預金金利も、2026年11月2日から年0.5%になっています。33〜34年ぶりの水準と報じられていますが、物価上昇と比べると、まだ十分とは言えません。

そうした中で2014年に始まったのが、運用益が非課税になるNISA（少額投資非課税制度）です。その後、2018年につみたてNISAが始まり、2024年には新しいNISAへと広がっていきました。

アベノミクスがNISAを生んだ、と単純に結びつけるつもりはありません。ただ、「預金だけでは増えにくい時代に、国として資産形成を後押ししたい」という流れの中で、時期が重なっていることは確かです。私は、家計が投資を身近に考えるきっかけになった期間だったと見ています。

■ 「あのとき始めていれば」より大切なこと

株価が上がった局面を振り返ると、つい「あのとき始めていれば」と思ってしまいます。そうした声を耳にすることもあります。でも、後から振り返れば、どんな相場も分かりやすく見えるものです。その時点では、先行きは誰にも分かりません。

だからこそ、次のことを意識してほしいと思っています。

① 生活費や急な出費への備えは、まず預金で確保する
② 余裕資金の範囲で、長く続けられる金額から始める
③ 一度に投じず、時間を分けて積み立てる
④ 円安・円高どちらに動いても慌てないよう、資産を分散する

もしあなたが今、「投資を始めるべきか迷っている」状態なら、相場が高いか安いかを当てようとするより、自分の生活と目標に合った無理のない形を考えるほうが、ずっと実りがあるはずです。

■ 政策の評価より、自分の家計への置き換えを

アベノミクスの評価は、これからも議論が続くでしょう。ただ私たちにできるのは、その時代に起きたことを材料にして、自分の家計に置き換えて考えることです。

低金利が続いていたとき、お金をどこに置いていたか。円安や物価の変化を、家計でどう感じたか。そして今、金利が上がり始めた中で、その置き場所は今のままでいいのか。振り返るだけでも、これからの備え方のヒントになります。

ニュースで経済政策や金利の話題を目にしたら、「私の家計だとどうなるかな」と一度立ち止まってみてください。その小さな習慣が、お金と上手につきあう第一歩になると、私は思っています。
