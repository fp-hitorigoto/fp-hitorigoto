## FP1級との重なり（2026-11-22 調査済み）

FP1級ドットコムの分野別索引（2014年〜2026年9月の全回）で出題実績を確認した。
出典: https://fp1-siken.com/succession.html ／ https://fp1-siken.com/oyo_keisan.html

### ⚠️ まず押さえること：応用編は計算問題しかない

**FP1級応用編（問63〜65）の相続・事業承継で出るのは、実質この4つだけ。**

| 論点 | 出題回数 |
|---|---|
| 類似業種比準価額 | 18回 |
| 純資産価額方式・併用方式 | 16回 |
| 相続税の総額・納付相続税額 | 11回 |
| 小規模宅地等の評価減の特例 | 6回 |

つまり**FP1級の応用編は「計算」であって、条文の言い回しを書かせる記述ではない。**
相続アドバイザー2級の記述式とは性質が違う。
**重なるのは基礎編（問42〜50・マークシート）のほう。**

## 1. 遺留分、足すのは何年以内？【相続アドバイザー2級】

- **答え**：10年以内
- **一言解説**：算定の基礎に加える相続人への贈与は10年以内。一方、侵害額から差し引く特別受益に期間の制限はない。足すのは十年、引くのは全部。
- **根拠**：民法1044条3項／1046条2項1号
- **FP1級**：基礎編5回（直近 2025年1月 問44）→ `#FP1級` を足す
- 動画：`01_足すのは十年_Shorts劇場型.mp4`（25.5秒）
- 状態：⬜未投稿

## 2. 相続登記が遅れたらどうなる？【相続アドバイザー2級】

- **答え**：法定相続分を超える部分は対抗できない
- **一言解説**：法定相続分までは登記がなくても対抗できる。超えた分だけが登記を要する。遅れれば差押えに負ける。
- **根拠**：民法899条の2
- **FP1級**：確認できず → **FPタグは付けない**
- 動画：`02_放棄は取り消せない_Shorts劇場型.mp4`（24.0秒）
- 状態：⬜未投稿

## 3. 相続放棄した人は保険金の非課税枠を使える？【相続アドバイザー2級】

- **答え**：使えない
- **一言解説**：非課税は相続人が取得した保険金に限られる。ただし枠を計算する「法定相続人の数」には放棄した人も入る。**使えるかどうかと、数えるかどうかは別。**
- **根拠**：相続税法12条1項5号／15条2項
- **FP1級**：基礎編3回＋応用編の相続税計算で使用 → `#FP1級` を足す
- 動画：`03_実質負担者は誰_Shorts劇場型.mp4`（31.5秒）
- 状態：⬜未投稿

## 4. 遺贈を実行できるのは誰？【相続アドバイザー2級】

- **答え**：遺言執行者のみ
- **一言解説**：遺言執行者がいるときは、相続人は遺贈を実行できない。なお就職の催告に答えなかったときは、**承諾したものとみなされる**（拒んだことにはならない）。
- **根拠**：民法1012条2項／1008条
- **FP1級**：「民法における遺言」基礎編6回 → `#FP1級` を足す
- 動画：`04_遺言執行者がいるならば_Shorts劇場型.mp4`（24.5秒）
- 状態：⬜未投稿

## 5. 相続時精算課税、相続のときはいつの価額？【相続アドバイザー2級】

- **答え**：贈与時の価額
- **一言解説**：値上がりしても贈与した時の価額のまま足す。だから値上がりしそうな財産に向く。そして一度選んだら暦年課税には戻れない。
- **根拠**：相続税法21条の15／21条の9第6項
- **FP1級**：基礎編9回で最頻出クラス → `#FP1級` を足す
- 動画：`05_一度選んだら戻れない_Shorts劇場型.mp4`（25.8秒）
- 状態：⬜未投稿

## 6. 秘密証書遺言に検認は必要？【相続アドバイザー2級】

- **答え**：必要
- **一言解説**：公証役場で「あるかどうか」は探せるが、原本は保管されない。だから検認がいる。検認がいらないのは公正証書遺言と、法務局に預けた自筆証書遺言だけ。
- **根拠**：民法1004条
- **FP1級**：保管制度2回＋「民法における遺言」6回 → `#FP1級` を足す
- 動画：`06_ねえ遺言はどこに眠ってるの_Shorts劇場型.mp4`（28.7秒）
- 状態：⬜未投稿
- 📌 **歌詞の「公正証書と秘密証書は公証役場」は“探す場所”の話。**検認の要否とは別、という引っ掛けをそのままクイズにした回。

## 7. 借家権割合は地域で違う？【相続アドバイザー2級】

- **答え**：全国一律30％
- **一言解説**：地域ごとに違うのは借地権割合のほう（路線価図の記号で確認する）。借家権割合に地域差はない。
- **根拠**：財産評価基本通達94

## 8. 預金の仮払いで足りないときは？【相続アドバイザー2級】

- **答え**：調停を申し立てて、仮分割の仮処分
- **一言解説**：家庭裁判所へ。なお仮払いで受け取った分は、遺産の一部分割で取得したものとみなされ、あとの分割で精算される。
- **根拠**：家事事件手続法200条3項／民法909条の2後段
- **FP1級**：基礎編3回（直近 2026年1月 問44） → `#FP1級` を足す
- 動画：`08_できない理由を先に言って_Shorts劇場型.mp4`（29.0秒）

## 9. 債権者が取り消せるのは、放棄？ 協議？【相続アドバイザー2級】

- **答え**：遺産分割協議
- **一言解説**：遺産分割協議は財産権を目的とする行為なので詐害行為取消権の対象になる。相続放棄は身分行為なので対象にならない。
- **根拠**：最判平成11年6月11日
- **FP1級**：該当なし → **FPタグは付けない**（銀行実務寄り）
- 動画：`09_登記の前に代位せよ_Shorts劇場型.mp4`（26.3秒）
- 状態：⬜未投稿
- 📌 **「協議は取り消せる」は詐害行為取消権の話。**いつでも自由に取り消せるという意味ではない。説明文で必ず「債権者が」と書く。

## 10. 除外合意・固定合意、そろえる3つは？【相続アドバイザー2級】

- **答え**：全員の合意・経産大臣の確認・家庭裁判所の許可
- **一言解説**：推定相続人全員の合意から始まり、経済産業大臣の確認を得てから家庭裁判所の許可を申し立てる。**確認が先、許可が後。**
- **根拠**：経営承継円滑化法7条・8条・9条
- **FP1級**：基礎編6回（直近 2026年5月 問50） → `#FP1級` を足す
