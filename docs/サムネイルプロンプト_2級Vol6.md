# 2級 Vol.6 サムネイル制作プロンプト集（全15曲）

相続・事業承継。**確定歌詞との照合済み**（2026-11-22）。`✅照合` が根拠。

## 🎯 フックの選び方
**「正しいこと」ではなく「受験生が間違えやすいこと」を書く。**
基準は ①引っかけられやすい ②理解しにくい ③混同しやすい。
→ 詳しくは `docs/サムネイルプロンプト_2級Vol4.md` の冒頭。

## 共通の手順

**添付する2枚**
1. **Vol.6の背景**：`Vol6/歌い手キャラクター_16x9/` から1枚（**全曲同じものに固定**）
   シャンデリアの豪奢な会場・男性・銀髪にサングラス。**14枚ある**（2026-11-22完成）
   📌**寄りの絵を選ぶこと。** 引きの絵はサムネイルでは弱い
   📌候補：`寄り_歌い上げ`（顔が見える／迫力がある）、`前傾_マイク接近`（顔は手で隠れる）
   ⚠️**左右反転しない**（人物の向きは1枚に固定するので問題にならない）
2. **体裁の見本**：`Vol3/サムネイル/FP2_Vol3_01_金融政策.png`（**最後まで固定**）

**保存先**：`Vol6/サムネイル/FP2_Vol6_NN_<制度名>.png`
