## 🎯 フックの選び方
**「正しいこと」ではなく「受験生が間違えやすいこと」を書く。**
基準は ①引っかけられやすい ②理解しにくい ③混同しやすい。
書き方は「〜は〇〇である」より「**〜でも〇〇のまま**」「**〜だけは違う**」。
→ 詳しくは `docs/サムネイルプロンプト_2級Vol4.md` の冒頭。

## 🟣 帯の光は **紫〜マゼンタ** にする（2026-11-26決定）

6巻を並べて分かった。**帯が青いのはVol.3・Vol.5・Vol.6の3つ**で、Vol.6は背景が紫なのに
帯だけ青く、Vol.5と似て見えた。

| 巻 | 背景 | 帯の光 |
|---|---|---|
| Vol.1 青緑のステージ / Vol.2 夕焼け / Vol.4 暗い金 | 暖色 | 金 |
| Vol.3 夜の青 / Vol.5 昼の青空 | 寒色 | 青 |
| **Vol.6 紫のホール** | 紫 | **紫〜マゼンタ**（6巻で唯一） |

→ テンプレートに次の3行を入れてある。**1曲目から紫で作り直す。**

```

帯の光は青ではなく、紫〜マゼンタ寄りにしてください。
文字の色（白と金）とレイアウトは、見本のまま変えないでください。
```

📌**見本は体裁の手本であって、色の手本ではない。** 背景の色が変わる巻では、
　 帯の色も巻ごとに決める。並べて初めて気づくので、**1枚目の時点で6巻を並べて見る。**

### 明るさの測り方
