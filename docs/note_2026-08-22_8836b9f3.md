# 国債の「想定金利3.8％」ってどういうこと？ 金利が上がると私たちの生活はどう変わるのか

## 政府自身が「金利は上がる」と言い始めた

最近、こんなニュースを目にした方もいるかもしれません。

「来年度の概算要求で、財務省が国債の利払い費の想定金利を3.0％から3.8％に引き上げる」

……正直、「国債？利払い費？自分には関係ない話では？」と思いましたよね。でも、これ、実はかなり私たちの生活に直結する話なんです。

少し噛み砕いて説明しますね。国債というのは、国が資金を借りるために発行する債券のこと。国はその借金に対して利子（利払い費）を支払っています。財務省がその利子を計算するときに使う「想定金利」を、今年度の3.0％から3.8％に引き上げようとしている、ということです。

つまり、政府自身が「これからは金利が上がっていく前提で予算を組まないといけない」と認めたわけです。長年「低金利・ゼロ金利」が当たり前だった時代が終わりを告げようとしているサインとして、FP的にはとても重要な動きだと感じています。

## 住宅ローンは「今がどっちか」を確認してほしい

金利上昇の影響が最も身近に感じやすいのが、住宅ローンです。

もしあなたが変動金利でローンを組んでいるなら、少し注意が必要です。変動金利は、日本銀行の金融政策の影響を受けやすく、日銀が利上げ方向に舵を切っている今、金融機関の基準金利も少しずつ動いています。たとえば3,000万円を変動金利で借りていた場合、金利が0.5％から1.5％に上がるだけで、月々の返済額は数万円単位で変わることもあります。「毎月の返済はなんとかなってるけど、金利が上がったら……」という方は、一度シミュレーションをしてみることをおすすめします。

一方、固定金利型のローンは、長期金利（主に10年国債の利回り）に連動するのが一般的です。今回の「想定金利3.8％」という水準が現実味を帯びてくると、固定金利もじわじわと上昇してくる可能性があります。「これから住宅購入を考えている」という方にとっても、金利の行方は無視できません。

実際にご相談を受けることがあるのですが、「変動か固定か」という選択は、単純に「今どちらが低いか」だけで決めるものではないんですよね。ご自身の収入の安定性や、万が一金利が上がったときに返済を続けられるかどうか、といった家計全体の耐性を踏まえて考えることが大切です。

## 預金金利が上がるのは嬉しいけれど……

「金利が上がるなら、預金の利息も増えてよかった！」という声もよく聞きます。確かにその通りで、メガバンクや地方銀行の定期預金金利も、ここ数年と比べると少しずつ上がってきています。長らく「銀行に預けても増えない」と言われてきましたが、少しずつ風向きが変わってきているのは事実です。

ただ、ここで気をつけてほしいのが「インフレとのバランス」です。金利が上がる局面というのは、たいていインフレ（物価上昇）が起きているときでもあります。預金金利が上がっても、物価の上昇スピードがそれを上回ってしまえば、実質的にお金の価値は目減りしていることになります。「預金金利が上がった＝資産が守られている」とは、必ずしも言えない点は覚えておいてください。

## 保険商品の利回りにも変化が

生命保険や個人年金保険にも、金利上昇の波は及びます。保険会社は、集めた保険料を主に債券などで運用して将来の保険金・年金を賄う仕組みです。金利が上がると運用利回りも改善されるため、新しく販売される貯蓄性の高い保険商品（個人年金保険や終身保険など）の予定利率が改善される傾向があるとされています。

もし「老後の備えに個人年金保険を検討している」という方なら、今後新たに発売される商品の条件が改善される可能性もあります。ただし、すでに加入済みの契約は一般的に予定利率が固定されているため、今の金利上昇の恩恵を直接受けることはほぼありません。「乗り換えたほうがお得では？」と考える前に、解約返戻金の水準や切り替えコストをきちんと確認することが大切です。

## 「金利が上がる時代」に合わせた家計の見直しを

「金利なんて難しい話、自分には関係ない」と思っていた方も、ここまで読んでいただければ少し意識が変わったのではないでしょうか。

住宅ローン・預金・保険・投資……どれも金利という見えない糸でつながっています。政府が「想定金利3.8％」で予算を組もうとしているということは、私たち家計も「低金利が続く前提」から「金利がじわじわ上がっていく前提」に、頭の中のベースを切り替えていく必要があるということです。

「自分のローンは大丈夫かな」「保険の見直しタイミングかな」「預金だけじゃなくて運用も考えたほうがいいかな」……そういった疑問が少しでも浮かんだ方は、ぜひ一度、家計全体を俯瞰して考えてみてください。何かあればFPに相談するのもひとつの手ですよ。

金利が変わる時代は、お金の使い方・備え方を見直す絶好のタイミングでもあります。難しく考えすぎず、まずは「自分の話」として、少しずつ向き合ってみてくださいね。
