## 🎯 フックの選び方（2026-11-22に確立）

**「正しいこと」ではなく「受験生が間違えやすいこと」を書く。**

| 選ぶ基準 | |
|---|---|
| ① 引っかけられやすい | 思い込みを裏切る論点 |
| ② 理解しにくい | 言葉が似ていて混同する論点 |
| ③ 混同しやすい | AとBの境界 |

📌**書き方は「〜は〇〇である」より「〜でも〇〇のまま」「〜だけは違う」。**
📌**過去問の出題実績を確認する**（FP2級ドットコムなど）。「どう問われたか」まで見る。

### 実例：2曲目
| | |
|---|---|
| 当初 | 「事業的規模の目安は5棟10室」 ← 正しいが、受験生は既に知っている |
| **採用** | **「5棟10室を超えても不動産所得のまま」** |
| 根拠 | 2019年5月 問32・2024年5月 問31。**規模が大きくなれば事業所得になると誤解させる引っかけ**として繰り返し出題 |

📌5棟10室が効くのは**青色申告特別控除のほう**（8曲目「65, 55, 10」で扱う）。曲の分担も整理されている。
