## 🎯 フックの選び方（2026-11-22に確立）

**「正しいこと」ではなく「受験生が間違えやすいこと」を書く。**

| 選ぶ基準 | |
|---|---|
| ① 引っかけられやすい | 思い込みを裏切る論点 |
| ② 理解しにくい | 言葉が似ていて混同する論点 |
| ③ 混同しやすい | AとBの境界 |

📌**書き方は「〜は〇〇である」より「〜でも〇〇のまま」「〜だけは違う」。**
📌**過去問の出題実績を確認する**（FP2級ドットコムなど）。「どう問われたか」まで見る。

### 実例：2曲目
| | |
|---|---|
| 当初 | 「事業的規模の目安は5棟10室」 ← 正しいが、受験生は既に知っている |
| **採用** | **「5棟10室を超えても不動産所得のまま」** |
| 根拠 | 2019年5月 問32・2024年5月 問31。**規模が大きくなれば事業所得になると誤解させる引っかけ**として繰り返し出題 |

📌5棟10室が効くのは**青色申告特別控除のほう**（8曲目「65, 55, 10」で扱う）。曲の分担も整理されている。

## 作り直す基準（2026-11-23に確立）

⚠️**1日2〜3枚の上限がある。迷ったら進むほうが得。**

| 作り直す | 作り直さない |
|---|---|
| **誤字がある** | 文字の揺れ |
| 文字が読めない・切れている | 色味の微妙な違い |
| 人物が極端に小さい／大きい | 背景の細部 |
| バッジの形が崩れている | 光の加減 |

**判断は等倍ではなく、実際に表示されるサイズで行う。**
YouTubeの検索結果は360px、関連動画は168px。等倍で粗探しをしない。

### 文字の揺れについて（構造的な限界）

ChatGPTの画像生成は日本語の文字を機械的に揃えられない。毎回わずかに揺れる。
作り直しても同じ程度の揺れが別の場所に出るだけで、運任せに1枚使うことになる。

根本的に直すなら**写真だけ生成して文字はPillowで乗せる**方式がある
（相続ADのまとめ動画サムネイル `09f_make_full_thumbnail_相続AD琥珀.py` がその作り方）。

**ただし今はやらない。** Vol.1〜3の全サムネイルがChatGPT製なのでシリーズの見た目が
変わってしまうし、金色の立体感・グロー・きらめきをPillowで再現するのは手間がかかる。
Vol.7以降など区切りのいいところで検討する。
