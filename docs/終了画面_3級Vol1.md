# 終了画面の設定 — 3級 Vol.1 ライフプランニングと資金計画（全10曲）

## やること（1本あたり1〜2分）

1. YouTube Studio → コンテンツ → 動画を選ぶ → **エディタ**（または動画の詳細 →「動画の要素」→ 終了画面）
2. 要素を2つ置く
   - **動画** → 「動画を選択」→ 下の表の「次に出す動画」
   - **チャンネル登録**
3. 位置は**末尾の5〜20秒**。歌が終わってからの区間に重ねる
4. 保存

> 💡 **2本目からは「動画からインポート」**で1本目の配置をコピーできる。
> リンク先だけ差し替えれば済むので、1本あたり1分を切る。

⚠️3級Vol.1〜3は**免責テロップがない**（ログ2026-10記録）。
　 歌の最後と重なるようなら、終了画面の表示時間を短め（5〜10秒）にする。

## 設計の考え方（2026-11-16 しゅうぞうさんと決定）

**1曲目→2曲目→…→最後→1曲目 の輪にする。** 受験生が周回するのに合う。

⚠️**再生リストから見ている人は、終了画面を押さなくても次へ進む**（自動再生）。
　 終了画面が効くのは**検索や関連動画から単発で来た人**。そこを分かったうえでやる。
⚠️終了画面は**クリックされないと進まない**。自動再生ではない。
　 それでも「これはシリーズだ」と伝わることと、**登録ボタンを同時に置ける**ことに価値がある。

📌本編にはCTAが1つもなかった（2026-11-02のログ）。**書き出し直しが不要**なので終了画面が最有力。
