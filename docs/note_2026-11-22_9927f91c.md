# 防衛費の増額は家計にどう効く？税負担の仕組みを暮らしの目線で整理

ニュースで「防衛費を増額」と聞いても、自分の手取りがどうなるのかは分かりにくいですよね。

「増税になるらしい」という話は耳に入っても、誰の、どの税金が、いつ、どれくらい変わるのかまでは、なかなか追いきれないものです。今回は、防衛費増額の財源と、すでに決まっている税負担の中身を、暮らしに引き寄せて整理してみます。

## まず全体像

2022年12月に安保関連三文書が改定され、2023〜2027年度の5年間で防衛力整備の総額を約43兆円とする方針が示されました。当初は、2027年度に、防衛関係費と関連する取組を合わせて、GDP比2%の水準を目指す計画でした。

その後の動きもお伝えしておきます。報道によると、高市首相は2025年度補正予算の段階で、GDP比2%の達成を前倒しする方針を示しました。さらに、2026年中に安保三文書を改定する方針も示されています。NHKは11月18日付で、次の5年間の防衛費について、財務省が50兆円台前半を目安とする案を示していると報じました。ただ、これは政府内の調整段階の案で、決定した内容ではありません。新しい財源や増税が決まったかどうかも、確認できていません。

現行の財源は、増税だけで賄うわけではなく、次のような手段を組み合わせる設計になっています。

・歳出改革（ほかの支出の見直し）
・決算剰余金の活用
・税外収入（防衛力強化資金への繰り入れ）
・税制措置（増税）

つまり「防衛費が増える＝すべて増税」ではありません。ここは押さえておきたいところです。

## 増税の中身は3つ（始まる時期がそれぞれ違います）

税制措置の柱は、法人税、所得税、たばこ税の3つです。財務省の見込みとして、2027年度の増収額は約1.3兆円と解説されています。なお、制度は変わることがあるため、最新の情報は国税庁や財務省の発表でご確認ください。

法人税（すでに開始）

法人税額に4%の付加税を課す仕組みで、2026年4月1日以後に開始する事業年度から適用されています。基準となる法人税額から年500万円が控除されるため、中小企業への影響には配慮されています。会社員の方にとっては直接の負担ではありませんが、勤め先やお取引先の業績を通じて、間接的に関わる可能性はあります。ただ、その影響の大きさや方向は、企業の規模や業種によって異なります。

所得税（2027年1月から）

所得税の開始時期は、2026年度の与党税制改正大綱で2027年1月と決まったと報じられています。基準所得税額に、1%の付加税（防衛特別所得税）が課されます。一方で、今は2.1%の復興特別所得税の税率が、1.1%に引き下げられます。二つの特別税を合わせた税率は2.1%で、今と変わりません。

ここで具体的に計算してみましょう。「所得税額」とは、収入そのものではなく、各種控除を差し引いたあとに計算された税額のことです。たとえば所得税額が30万円の方の場合です。

・現行の復興特別所得税：30万円×2.1%＝6,300円
・見直し後の復興特別所得税：30万円×1.1%＝3,300円
・防衛特別所得税：30万円×1.0%＝3,000円
・合計：3,300円＋3,000円＝6,300円

この計算上は、毎年の負担額は変わらない形になります。「増税」という言葉の印象とは少し違いますよね。ただし、復興特別所得税を課す期間は10年延長され、2047年までになると解説されています。毎年の額は同じでも、負担する期間が延びる点は、長い目で見て押さえておきたいところです。

たばこ税

加熱式たばこの課税方式の見直しが、2026年4月と10月の2段階で行われ、税率の段階的な引き上げが2027年4月から予定されていると解説されています。喫煙される方は、引き上げ幅などの詳細を、一度確認しておくと安心です。

## 自分ごととして考えるポイント

では、私たちは何を意識すればよいのでしょうか。

① 「増税」の見出しだけで判断しない
先ほどの所得税の例のように、制度の組み替えによって、毎年の負担額が計算上は変わらないケースもあります。見出しだけで不安になるより、自分の税額で試算してみるのがおすすめです。

② 立場によって影響は変わる
会社員、個人事業主、経営者、喫煙の有無などで、影響の受け方は異なります。「みんなが損をする」「誰も困らない」と一括りにはできません。

③ 家計の土台を整えておく
税制は今後も見直される可能性があります。次の5年間の規模や財源も、年末に向けて議論が続きます。だからこそ、毎月の支出の把握、iDeCoやNISAなど制度を活用した資産形成、保険の見直しといった「自分で動かせる部分」を整えておくことが大切です。

## まとめ

防衛費の増額は、遠い国の話のようでいて、税制を通じて私たちの家計や勤め先にも関わってきます。法人税はすでに2026年4月から始まり、所得税は2027年1月からです。ただ、所得税は、防衛特別所得税の創設と復興特別所得税の引き下げがセットなので、毎年の額は変わらない形です。そのぶん、課税期間の延長という長期の論点があります。

漠然とした不安を抱えたままになるのは、気持ちの面でもしんどいですよね。まずは、ご自身の源泉徴収票などで所得税額を確認し、簡単に試算してみてください。数字で見えると、不安は意外と小さくなるものです。
