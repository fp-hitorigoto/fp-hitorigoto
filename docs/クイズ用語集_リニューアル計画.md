## ⚠️ 作業の事故と対策（2026-11-23）

**正規表現で問題を置換しようとして、index.html を壊した。**
`\{id:5,category:.*?\}(?=,\{id:|\s*\])` の終わり判定が甘く、
問5から最後の問題まで一気に飲み込んで**120問が5問になった**。
原因は、問題の区切りが `},\n  {id:` と改行を挟むのに、
lookahead を `,\{id:`（改行なし）にしていたこと。

**公開版から復旧できた**（前日にデプロイ済みだったため）。本番は無傷。

### → 今後は正規表現で問題を置換しない

**波括弧を数えて範囲を特定する。**

```python
def span(src, n):
    m = re.search(r'\{id:%d,category:' % n, src)
    i, depth = m.start(), 0
    while i < len(src):
        if src[i] == '{': depth += 1
        elif src[i] == '}':
            depth -= 1
            if depth == 0: return (m.start(), i+1)
        i += 1
```

置換の前に `blk.count('{id:') == 1` で**他の問題が混ざっていないか必ず確認する**。
複数直すときは**後ろの問題から**置換して位置ずれを防ぐ。

# 第3段階：用語集に検索を付けた（2026-11-23）

## なぜ検索からか

4アプリの機能を洗い出したところ、**クイズは十分**だった（分野選択・問題数選択・復習モード）。
一方**用語集は入力欄が1つもなく、カードを1枚ずつめくるしかなかった。**
2級は310語あるので、「あの用語なんだっけ」と思っても探せない状態だった。

## 入れたもの（3級・2級の用語集）

- 分野選択画面のいちばん上に**検索欄**
- **用語名と定義の両方**から絞り込む（「58万円」「債券」でも引ける）
- 結果は一覧で出し、タップでその語のカードへ（前後の移動もその結果の中でできる）
- **用語名に一致したものを先に並べる**（定義だけ一致したものは後ろ）
- 空欄に戻すと、元の分野選択画面に戻る

### 作り

```js
const inTerm = words.filter(w => w && w.term.includes(q));
const inDef  = words.filter(w => w && !w.term.includes(q) && w.definition.includes(q));
searchHits = inTerm.concat(inDef);
```

- 既存の `startCards()` には手を触れず、`openSearchHit(i)` を別に用意した
- 分野選択の中身は `#browse-area` で囲み、検索中は隠すだけにした
- `esc()` でHTMLエスケープしている（用語に記号が入っても壊れない）

### 検証

| 検索語 | 結果 |
|---|---|
| 58万円（2級） | 4件。基礎控除・配偶者控除・扶養控除・所得控除の種類 |
| 債券（3級） | 5件。**債券の利回り → 債券の信用格付**が先頭に来る |
| 第三分野（2級） | 1件。カードを開くと曲リンクも正しく出る |

コンソールエラーなし。語数・穴なしも確認済み。
